# Keyboard shortcuts

FootageFlow keeps standard system editing shortcuts intact.

| Action | macOS | Windows |
|---|---|---|
| Command Palette | `⌘K` | `Ctrl+K` |
| Focus Quick Search | `⌘F` | `Ctrl+F` |
| Global Search | `⌘⇧G` | `Ctrl+Shift+G` |
| New Project | `⌘N` | `Ctrl+N` |
| Open Projects | `⌘O` | `Ctrl+O` |
| Open Downloads | `⌘⇧D` | `Ctrl+Shift+D` |
| Open Research Notes | `⌘⇧R` | `Ctrl+Shift+R` |
| Open Favorites | `⌘⇧F` | `Ctrl+Shift+F` |
| Open Settings | `⌘,` | `Ctrl+,` |
| Close a transient panel | `Esc` | `Esc` |

In Command Palette and Global Search, use Up/Down to select an item, Enter to run or open it, and Escape to close the panel.
