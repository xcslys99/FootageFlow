# FootageFlow v0.7.4

FootageFlow v0.7.4 improves update visibility without taking control away from the user.

## Improved

- FootageFlow now checks for new stable releases on every app launch when online.
- Outdated installations receive an update dialog with the current version, latest version, publication date, and the latest release notes.
- Choosing **Not Now** dismisses the reminder only for the current session. If the app remains outdated, the next complete launch checks and reminds again.
- Offline, timeout, rate-limit, GitHub availability, and invalid-response failures remain silent during startup. Manual checks continue to show a friendly status.
- Legacy v0.6.0-and-earlier users receive manual-upgrade guidance in the README and their older Release pages.

## Safety and privacy

- **View Update** opens only the official `xcslys99/FootageFlow` GitHub Release page.
- Release Notes are shown as bounded, safe plain text; embedded HTML or scripts are never executed.
- The update request does not send projects, searches, downloads, clipboard contents, API keys, local paths, or other personal data.
- FootageFlow never silently downloads or installs an update and never forces an update.

## Platforms

- macOS 15+ on Apple Silicon
- Windows 11 x64

The macOS app is Ad Hoc signed and not notarized. The Windows installer is not code-signed. Verify the attached SHA-256 files before installing.
