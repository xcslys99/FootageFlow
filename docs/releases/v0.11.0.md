# FootageFlow v0.11.0

## Added

- Five no-key source entries: **Dareful**, **ESA Multimedia**, **Mazwai**, **DVIDS**, and **British Pathé**.
- Dareful public direct search, preview, and best-effort download through the existing Download Manager. Dareful results preserve the source-supplied **CC BY 4.0** attribution requirement in FootageFlow's normal source sidecars.
- ESA Multimedia public direct search for image/video discovery. ESA media stays **discovery-only** in this release because rights vary by item; open the original page to confirm reuse terms.
- Official-search actions for Mazwai, DVIDS, and British Pathé. They remain **limited-discovery** providers where their public sites currently restrict automated result retrieval.

## Improved

- macOS and Windows now share the same 22-provider catalog, provider capabilities, no-key migration, failure isolation, and source/rights behavior.
- Existing users receive the new no-key sources automatically without changing stored settings or API keys.

## Safety and rights

- FootageFlow does not bypass CAPTCHA, WAF challenges, sign-in, cookies, paywalls, or access controls.
- A successful discovery or download does not grant reuse rights. Verify the original source page before publishing.

## Installation

- **macOS 15+ Apple Silicon:** download `FootageFlow-0.11.0-macOS-arm64.dmg`.
- **Windows 11 x64:** download `FootageFlow-Setup-0.11.0-Windows-x64.exe` or the portable ZIP.
- Verify the accompanying SHA-256 checksum before installing. The macOS build is Ad Hoc signed and not notarized; the Windows package is not code-signed yet.
