# FootageFlow v0.3.0 — Discovery Update

FootageFlow v0.3.0 expands the cross-platform footage discovery workflow from five to nine sources while preserving the v0.2.0 macOS and Windows architecture.

## Added

- NASA Image and Video Library
- Library of Congress
- National Archives Catalog (user API key for full in-app search; limited official-search mode without a key)
- Europeana (user API key for full in-app search; limited official-search mode without a key)
- Advanced source, media type, year, duration, resolution, rights, and downloadability filters
- Downloadable Only
- Multi-select, Select All Visible, and Clear Selection
- Batch download through the existing bounded Download Manager
- Add selected results to an existing or new project
- Copy Source and Copy Attribution
- Retry Failed downloads

## Improved

- Provider capability and API/keyless mode modeling
- Structured rights metadata without inferring licenses or Public Domain status
- Progressive provider result handling and isolated failures
- Secure NARA and Europeana credentials in macOS Keychain and Windows Credential Manager
- English and Simplified Chinese parity

## Supported platforms

- macOS 15+ on Apple Silicon
- Windows 11 x64

Windows 10 has not completed release validation and is not claimed as supported.

## Installation

### macOS

Download `FootageFlow-0.3.0-macOS-arm64.dmg`, verify its `.sha256`, open the disk image, and drag FootageFlow to Applications. The app is Ad Hoc signed and not notarized.

### Windows

Download `FootageFlow-Setup-0.3.0-Windows-x64.exe`, verify its `.sha256`, and run the setup wizard. A checksummed portable ZIP is also available. The installer is self-contained and does not require Python, Node.js, Swift, .NET, yt-dlp, or FFmpeg to be installed separately. It is not code-signed, so SmartScreen may show an unrecognized-app warning.

## Provider and rights notes

- Pexels and Pixabay use official APIs when a user key is present and best-effort direct search otherwise.
- NASA and Library of Congress use official public APIs without API keys.
- National Archives and Europeana never scrape HTML to bypass an API key requirement; no-key mode opens official search.
- YouTube search/download without a Data API key remains best-effort through bundled yt-dlp.
- Direct download availability never implies permission to reuse. Unknown rights remain unknown and must be verified on the original source page.

This product uses the National Archives Catalog API but is not endorsed or certified by the National Archives and Records Administration.

## Known issues

- The macOS app is not notarized and the Windows installer is not code-signed.
- National Archives and Europeana require the user's own API key for complete in-app search.
- Best-effort YouTube, Pexels, and Pixabay behavior can be limited by upstream changes, regional restrictions, login requirements, or rate limits.
- Preview and direct download depend on each item exposing a compatible official media URL.
