# FootageFlow v0.7.0

FootageFlow v0.7.0 adds an optional, notification-only software update experience to macOS and Windows.

## What's new

- FootageFlow checks the latest official GitHub Release once when the app starts.
- When a newer version exists, the app shows the current and latest versions, publication date, release title, and full release notes.
- **View Update** opens this repository's official GitHub Release page.
- **Remind Later** defers that same release for 24 hours. A still newer release can be shown immediately.
- **Settings → Software Updates → Check for Updates** provides a manual check.
- Offline, timeout, rate-limit, and unavailable states use readable localized messages in all ten UI languages.
- macOS and Windows share release parsing, semantic version comparison, official-link validation, and reminder rules.

## Safety and privacy

FootageFlow does not force, silently download, or automatically install an update. The startup check sends only the current app version and normal HTTPS request metadata to GitHub's public Releases API. It does not include credentials, searches, projects, downloads, clipboard contents, or local paths.

## Important compatibility note

FootageFlow v0.6.0 and earlier do not contain an update checker, so they cannot receive this notification retroactively. Install v0.7.0 manually once; future official releases can then be detected in the app.

## Supported platforms

- macOS 15+ on Apple Silicon
- Windows 11 x64

The macOS build is Ad Hoc signed and not notarized. The Windows installer is not code-signed. Verify downloads using the SHA-256 files attached to the official Release.
