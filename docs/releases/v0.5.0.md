# FootageFlow v0.5.0 — Search Expansion and Link Downloader

Release candidate notes. Publish only after macOS and Windows CI, installer, clean-install, smoke, security, and artifact checks pass.

## Added

- Pagination and Load More across supported providers
- PeerTube / SepiaSearch, Videvo, Videezy, Mixkit, Coverr, and Vimeo discovery
- Link Downloader for one or more public media URLs
- Best Quality, source-available 1080p/720p/480p, Audio Only, and source-available subtitles
- Feedback & Community with safe GitHub Issue, Discussions, repository, and release links

## Supported platforms

- macOS 15 or later on Apple Silicon
- Windows 11 x64

## Link download boundaries

Download availability depends on the source website, individual media, access permissions, and platform changes. FootageFlow does not import browser cookies, bypass DRM or sign-in, access private videos, or unlock paid/member content. Link analysis rejects embedded credentials, sensitive query parameters, and local/private-network addresses; DRM-marked formats are excluded. Users must follow source terms, copyright rules, and applicable law.

## Known limitations

- Videvo, Videezy, and Mixkit open official search rather than scraping result pages.
- Vimeo is discovery-only by default.
- yt-dlp interoperability is best-effort and can change upstream.
- FootageFlow does not bundle FFmpeg, so separate-stream merging and subtitle embedding are not guaranteed.
- The macOS build is Ad Hoc signed and not notarized; the Windows installer is not code-signed.

## Checksums

Every release artifact must have an adjacent portable SHA-256 checksum before publication.
