# FootageFlow v0.7.3

FootageFlow v0.7.3 is a creator-workflow stability release for macOS and Windows. It keeps the v0.7.2 ten-language compound search and existing Download Manager unchanged while closing several validation and error-handling gaps.

## Fixed

- Clipboard link detection no longer repeats a URL already offered during the current app session.
- Direct media with missing resolution metadata can use the editing-compatible MP4 workflow instead of being rejected by every height filter.
- Vimeo OAuth 401 responses are explained as an access/login requirement. FootageFlow does not import cookies or bypass authentication.
- Generic media failures no longer incorrectly identify every source as YouTube.

## Hardened

- Openverse explicitly requests `mature=false` and defensively removes any response item marked mature.
- macOS and Windows release pipelines now perform real YouTube, Dailymotion and direct-media analysis, then create and validate a 10-second editing-compatible MP4 with source sidecars.

## Validation

- 44 offline Swift tests.
- macOS real creator workflow: 12/12 checks passed, including bundled tools, three source analyses, 10-second duration, MP4/H.264/yuv420p/AAC, fast-start, and both sidecars.
- Windows 11 x64 release gate: shared core, WPF, real creator workflow, packaging, installer, clean install, startup, uninstall, and checksums.

## Platforms

- macOS 15+ on Apple Silicon
- Windows 11 x64

The macOS app is Ad Hoc signed and not notarized. The Windows installer is not code-signed. Verify the attached SHA-256 files before installing.
