# FootageFlow v0.13.0 — Smart Duplicate Review

## New

- Search results can be viewed as **Grouped** or **All Results**. Suspected duplicate versions remain individually available for preview, project use, download where supported, and source/attribution copy.
- Shared macOS and Windows duplicate analysis uses canonical IDs/URLs, corroborated metadata, and bounded local thumbnail fingerprints. It distinguishes exact, likely, and possible matches without downloading full videos or using a cloud similarity service.
- A **Recommended version** helps with workflow selection. It is not a rights or copyright judgment. Each original result keeps its own license and Unknown remains Unknown.
- Duplicate detection and default grouping are on by default and can be changed in Settings. New labels are available in all ten interface languages.

## Creator workflow improvements since v0.12.1

- Switching media type after a search requests the new type instead of showing a misleading empty result.
- Repeated query text is coalesced before Provider requests, while all ten editable language slots remain visible.
- The source selector and discovery-only notices are more compact. Public-source access errors no longer misleadingly demand an API key.
- On Windows, the source list starts collapsed so result cards remain visible in smaller windows; every source can still be expanded and toggled.
- Project details, Link Downloader project selection, and project-scoped download reuse have been improved.

## Platforms and installation

- macOS 15+ on Apple Silicon: `FootageFlow-0.13.0-macOS-arm64.dmg`
- Windows 11 x64: `FootageFlow-Setup-0.13.0-Windows-x64.exe` or the portable ZIP

Verify the attached SHA-256 checksums. The macOS app is Ad Hoc signed but not notarized, and the Windows installer is not code-signed; first-run OS warnings may therefore appear. FootageFlow does not force updates.

## Known limitations

Similar footage can be missed or grouped incorrectly, especially after heavy edits or when source metadata and thumbnails are poor. Expand a group and verify the source and rights for the exact version you intend to use. A successful download does not establish permission to reuse media.
