# FootageFlow v0.13.0 — Draft Release Notes

This is a release candidate draft, not a published release.

## Added

- Smart Duplicate Review groups cross-provider search results while preserving every original version and action.
- Local metadata and thumbnail-fingerprint evidence distinguishes exact, likely, and possible matches.
- Grouped and All Results views, a workflow-only recommended version, and default-on settings on macOS and Windows.

## Privacy and rights

Duplicate analysis runs locally and does not download full videos for comparison. It never transfers a license or rights status between versions. A recommendation does not provide copyright clearance.

## Validation required before publication

Finish macOS packaging and real UI acceptance, Windows CI build/package/installer acceptance, and manual VoiceOver/Narrator review. Do not link this draft as the latest release until a release is approved and published.
