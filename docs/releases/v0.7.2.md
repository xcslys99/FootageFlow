# FootageFlow v0.7.2

FootageFlow v0.7.2 fixes compound-topic searches such as `广州美食` and adds one shared ten-language search plan to macOS and Windows.

## What's new

- Every search now creates a complete compound query in English, Simplified Chinese, Traditional Chinese, Spanish, Brazilian Portuguese, Japanese, Korean, German, French, and Russian.
- The input language is preferred first, followed by the interface language, English, and the remaining languages.
- The search editor shows input-language and English queries by default. **View all languages** exposes every query for editing or disabling.
- Input-language and English visual expansions remain bounded; a complete plan never exceeds 14 queries.
- Search waves respect a 12-request global limit, two requests per official/public Provider, and one request per direct/tool Provider.

## Fixed

- `广州美食` no longer becomes a zero-result search when Apple Translation suggests `Guangzhou delicacies`.
- Translation and expansion phrases can retrieve candidates but cannot add mandatory concepts to the user's original intent.
- Guangzhou/Canton/Cantonese, cuisine, gastronomy, dim sum, yum cha, morning tea, Cantonese dishes, seafood, and street-food vocabulary is recognized across the supported languages.
- One Provider's 403, 429, timeout, or temporary block remains isolated from all successful sources.

## Validation

- 43 offline unit and fixture tests passed.
- macOS Ad Hoc signature, binary privacy scan, offline self-test (90 checks), and real public-provider smoke test passed.
- A real `广州美食` run retrieved 323 candidates. The old Provider order measured 7 relevant items in its Top 20; Balanced ranking measured 20/20.
- Windows 11 x64 is built, installed, launched, tested, uninstalled, and packaged on the clean GitHub Actions Windows runner.

## Platforms

- macOS 15+ on Apple Silicon
- Windows 11 x64

The macOS app is Ad Hoc signed and not notarized. The Windows installer is not code-signed. Check the attached SHA-256 files before installing.
