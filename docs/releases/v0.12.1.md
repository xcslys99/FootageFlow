# FootageFlow v0.12.1

## Compound search relevance fix

- Fixed compound searches that could lose an unrecognized place or proper noun after recognizing a broad subject. Searching `西安美食` no longer sends generic `cuisine` or `food` requests.
- Added complete ten-language Xi'an and Berlin mappings. Searches such as **Xi'an food** and **Berlin night scenes** keep the location in every canonical query.
- The default **Balanced** relevance mode now requires source metadata to support every required concept. A food-only result cannot pass a location-plus-food search, and another city’s night scene cannot pass a Berlin night-scene search.
- Unknown CJK and Latin entities remain mandatory in every generated query. Translation-derived spellings are retrieval aliases only and never weaken the original request.
- Improved Library of Congress reliability when its public catalog responds just beyond the shared Provider timeout, without delaying other search sources.

## Platforms

- macOS 15+ on Apple Silicon
- Windows 11 x64

## Installation

- **macOS:** download `FootageFlow-0.12.1-macOS-arm64.dmg`, open it, and drag FootageFlow to Applications.
- **Windows:** download `FootageFlow-Setup-0.12.1-Windows-x64.exe`; a portable ZIP is also included.

Verify the attached SHA-256 checksum before opening a release asset. The macOS app is Ad Hoc signed but not notarized, and the Windows installer is not code-signed yet, so Gatekeeper or SmartScreen may require an explicit first-run confirmation.
