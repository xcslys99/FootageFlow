# FootageFlow v0.2.0

FootageFlow now supports Windows while keeping the existing macOS experience and one shared provider core.

## Supported platforms

- macOS 15 or later on Apple Silicon
- Windows 11 x64

Windows 10 has not completed the same release validation and is not declared supported in this release.

## Highlights

- Added the native Windows WPF application and self-contained Inno Setup installer.
- Added shared Pexels, Pixabay, Wikimedia Commons, Internet Archive, and YouTube provider behavior across macOS and Windows.
- Added Windows projects, favorites, search history, downloads, cancel/retry, preview, settings, license/source metadata, and English/Simplified Chinese switching.
- Added Windows Credential Manager storage for optional Pexels, Pixabay, and YouTube API keys.
- Added Pexels and Pixabay official API mode when a key exists and best-effort direct search when no key exists.
- Added local yt-dlp best-effort YouTube search and downloads without browser-cookie import or DRM bypass.
- Preserved isolated Provider failures so a 403, 429, timeout, or unavailable source cannot discard other successful results.

## Installation

### Windows

Download `FootageFlow-Setup-0.2.0-Windows-x64.exe`, verify it with the attached `.sha256` file, then double-click it. The setup package includes the required application runtime and tools; Python, Node.js, Swift, .NET, yt-dlp, and FFmpeg do not need to be installed separately.

### macOS

Download `FootageFlow-0.2.0-macOS-arm64.dmg`, open it, and drag FootageFlow into Applications.

## Known issues

- The Windows installer is not code-signed. Microsoft Defender SmartScreen may show an unrecognized-app warning. Only continue with the official Release asset after verifying its SHA-256 checksum.
- The macOS package is Ad Hoc signed and not notarized. macOS may require **System Settings → Privacy & Security → Open Anyway** on first launch.
- Pexels and Pixabay direct search is best-effort. An optional API key enables their more reliable official API mode.
- YouTube search and downloading through yt-dlp is best-effort and can be limited by region, login requirements, rate limits, rights restrictions, or platform changes.
- Internet Archive and other sources are not assumed to be Public Domain. Verify every asset's original source page and license before reuse.

## Checksums

SHA-256 checksum files are attached beside every DMG, Windows installer, and portable archive.
