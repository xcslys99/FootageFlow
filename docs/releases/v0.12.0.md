# FootageFlow v0.12.0

## Keyboard & accessibility update

- Use FootageFlow’s core creator workflow with a keyboard: search, filters, result actions, Projects, Download Manager, Settings, Link Downloader, Command Palette, Global Search, and dialogs.
- **Clear Filters** returns filtering to normal without erasing your current query, keyword plan, project choice, or already loaded results.
- macOS VoiceOver and Windows Narrator now receive clearer labels and states for navigation, providers, search results, downloads, project lists, thumbnail retry, and icon-only actions.
- Windows keyboard focus now has a clear accent outline. On Windows, Command Palette and Global Search return focus to the invoking control after closing; macOS exits these panels without a keyboard trap.
- The update dialog is keyboard-complete, begins at **Not Now**, exposes Release Notes, and explains that **View Update** opens the official GitHub Release page.
- New accessibility text is available in all ten FootageFlow interface languages.

## Update safety

FootageFlow’s updater remains notification-only. It never silently downloads, installs, skips a version permanently, or forces an update. **View Update** opens the official Release page in your browser; you decide whether to install a new version.

## Supported platforms

- macOS 15+ on Apple Silicon
- Windows 11 x64

## Installation

- **macOS:** download `FootageFlow-0.12.0-macOS-arm64.dmg`, open it, and drag FootageFlow to Applications.
- **Windows:** download `FootageFlow-Setup-0.12.0-Windows-x64.exe`; a portable ZIP is also included.

Verify the attached SHA-256 checksum before opening a release asset. The macOS app is Ad Hoc signed but not notarized; the Windows installer is not code-signed yet, so macOS or SmartScreen may require an explicit first-run confirmation.
