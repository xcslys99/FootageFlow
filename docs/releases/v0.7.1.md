# FootageFlow v0.7.1

FootageFlow v0.7.1 fixes compound-query relevance on macOS and Windows.

## What changed

- Added two-stage retrieval: broad Provider candidate discovery followed by shared local relevance ranking
- Added concept-group coverage so a Balanced `台湾美食` search must cover both Taiwan and food concepts
- Added weighted title, tags, category, description, creator/channel, Provider, and matched-query signals
- Added Precise, Balanced, and Broad modes; Balanced is the default
- Added usable Provider metadata from PeerTube/SepiaSearch, Internet Archive, Pixabay, and Wikimedia to the ranker
- Added all ten interface-language translations for the new mode control

## Validation

- 38 cross-platform shared tests pass locally, including a fixed Precision@20 relevance suite
- The fixed `台湾美食` Top 20 is 20/20 relevant while retaining non-exact titles such as `Taipei beef noodle soup`
- A real public-provider run retrieved 122 candidates. The old Provider order contained only 2 judged-relevant items in its Top 20; Balanced returned 14 results and all 14 passed the relevance review.
- A full installed-app GUI search returned 35 real results; its first 20 were manually reviewed and all 20 were relevant to both Taiwan and food.
- The Windows shared Core Host exposes the same `rankAssets` behavior used by macOS; clean Windows packaging and GUI tests run in GitHub Actions

## Install

- macOS 15+ Apple Silicon: open the DMG and drag FootageFlow to Applications
- Windows 11 x64: run the installer

The macOS build is Ad Hoc signed and not notarized. The Windows installer is not code-signed. Verify the attached SHA-256 checksum before installation.
