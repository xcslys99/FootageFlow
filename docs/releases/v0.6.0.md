# FootageFlow v0.6.0 — Creator Workflow Update

FootageFlow v0.6.0 adds creator-oriented search and output tools to both supported desktop editions without replacing the existing search, project, or download workflows.

## Added

- Download a full public media item or a validated start/end clip through the existing Link Downloader and Download Manager.
- Rule-based Smart Search Expansion with up to five visible, editable queries and provider-specific request budgets. No paid AI API is required.
- Original, editing-compatible H.264/AAC MP4, and M4A audio output presets.
- Optional local clipboard media-link detection, disabled by default and active only while FootageFlow is in the foreground.
- Openverse image/audio search with pagination and item-specific rights and attribution metadata.
- Dailymotion public video discovery with pagination and Open Original behavior.

## Improved

- Output preset and clip-time metadata are retained in download rows, history, filenames, and both source sidecars.
- The bundled yt-dlp workflow now includes pinned FFmpeg/FFprobe tools for section downloads, stream merging, audio extraction, and verified editing-compatible output.
- Search query coverage, cross-query de-duplication, and provider failure isolation.
- macOS and Windows creator-workflow parity in all ten interface languages.

## Supported platforms

- macOS 15 or later, Apple Silicon (`arm64`)
- Windows 11 x64

Windows 10 and Intel Mac have not completed release validation and are not declared supported.

## Installation

- macOS: `FootageFlow-0.6.0-macOS-arm64.dmg`
- Windows: `FootageFlow-Setup-0.6.0-Windows-x64.exe`
- Optional portable Windows package: `FootageFlow-0.6.0-Windows-x64-portable.zip`

Verify each download with its adjacent `.sha256` file. The macOS build is Ad Hoc signed and not notarized. The Windows installer is not code-signed, so SmartScreen may show an unrecognized-app warning.

## Safety and limitations

Link analysis and downloading are best-effort. Availability depends on the source, media item, permissions, authentication requirements, regional restrictions, rate limits, and platform changes. FootageFlow does not import browser cookies, bypass DRM or sign-in, unlock private/member/paid content, or promise that every link is downloadable.

Dailymotion is primarily a discovery provider. A Dailymotion URL can separately be sent to Link Downloader for a best-effort attempt. Openverse rights labels come from item metadata and must still be checked on the original page before reuse.

Clipboard detection is optional, disabled by default, local-only, and never uploads or logs clipboard content.

## Checksums

SHA-256 files are generated beside each release artifact during the verified release build. The final values are attached to the GitHub Release after the macOS and Windows release-candidate checks pass.
