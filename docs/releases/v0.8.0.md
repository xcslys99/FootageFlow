# FootageFlow v0.8.0

## Highlights

- Export project attribution reports in Markdown, CSV, JSON, or offline HTML.
- Generate concise or detailed credits from Provider-supplied source metadata.
- Review a project with Rights Audit filters before publishing.
- Create a portable `.footageflowproject` backup for macOS and Windows without bundling media or credentials.
- Find exact and likely duplicate project items locally, save a decision, and safely remove only a project association when needed.
- Export a numbered PNG contact sheet using cached/provider thumbnails, local images, or a best-effort FFmpeg video frame.

## Privacy and rights

FootageFlow never treats a successful download as permission to reuse media. Reports and backups omit credentials, cookies, tokens, raw clipboard content, and absolute local paths by default. A backup stores metadata only, never media binaries.

Rights Audit is an organization aid, not legal clearance. Always verify the original source page before publishing.

## Packages

- `FootageFlow-0.8.0-macOS-arm64.dmg` — macOS 15+ on Apple Silicon
- `FootageFlow-Setup-0.8.0-Windows-x64.exe` — Windows 11 x64 installer
- `FootageFlow-0.8.0-Windows-x64-portable.zip` — Windows 11 x64 portable package
- `.sha256` checksum files for every package

FootageFlow does not silently download, install, or force updates. Existing v0.7+ installs can show this release in the in-app update dialog when online.
