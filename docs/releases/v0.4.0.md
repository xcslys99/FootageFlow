# FootageFlow v0.4.0

FootageFlow v0.4.0 expands the complete macOS and Windows interface from two languages to ten and makes optional API setup easier to discover without interrupting first launch or search.

## Added

- Traditional Chinese, Spanish, Brazilian Portuguese, Japanese, Korean, German, French, and Russian
- English remains the first-launch default; language changes remain immediate and persistent
- A localized note below Quick Search recommends the free official APIs for National Archives, Europeana, and YouTube and points users to Settings
- Installer and app-bundle resources for all ten languages
- Locale-key, placeholder, fallback, persistence, and recommendation-copy tests

## Supported platforms

- macOS 15 or later on Apple Silicon
- Windows 11 x64

## Install

- macOS: download `FootageFlow-0.4.0-macOS-arm64.dmg`, open it, and drag FootageFlow into Applications.
- Windows: download `FootageFlow-Setup-0.4.0-Windows-x64.exe`, verify the adjacent SHA-256 file, and run the installer.

Normal use does not require a terminal, Python, Node.js, Swift, .NET, yt-dlp, or FFmpeg installation. API keys remain optional and are stored only in macOS Keychain or Windows Credential Manager.

## Known limitations

- The macOS build is Ad Hoc signed and not notarized.
- The Windows installer is not code-signed, so SmartScreen may show an unrecognized-app warning.
- National Archives and Europeana need the user's own API key for complete in-app results.
- YouTube keyless search and downloading are best-effort and can fail because of upstream restrictions or changes.
- Always verify unknown or incomplete rights metadata on the original source page.

## Checksums

Each downloadable artifact has a matching `.sha256` file in this Release.
