# FootageFlow v0.10.0 — Workspace & Accessibility Update

## New local workspace

- Use **Global Search** to find projects, media, favorites, downloads, history, Saved Searches, research references, and known local-media records already saved by FootageFlow.
- Use **Saved Searches** to keep and rerun a query with its scope, filters, relevance mode, and enabled sources.
- Review dynamic **Smart Collections**, project summaries, and manual **Provider Health** checks from Workspace.
- Open the **Command Palette** for keyboard-first navigation to the main workflows.

## Accessibility and privacy

- Improved VoiceOver/Narrator labels, status descriptions, keyboard navigation, and native focus handling.
- Workspace search is local-only. It does not crawl disks, upload workspace data, or index API keys, cookies, tokens, or raw logs.

## Platform support

- macOS 15+ on Apple Silicon
- Windows 11 x64

FootageFlow remains a user-controlled application: this update does not add mandatory accounts, analytics, cloud sync, forced updates, or background provider polling.

## Distribution note

The macOS build is Ad Hoc signed and is not notarized. The Windows installer is unsigned. SHA-256 checksum files are included with the release assets for independent verification.
